# Dunsin Natural Writing — reusable writing skill

This is an **original, independent writing assistant skill** developed for Dunsin Fakorede. It takes inspiration only from the broad idea that writing should sound natural and maintain its meaning. It does **not** implement, copy, or promise the detector-evasion claims advertised by the Turnitout-Humanizer project.

## Contents
- `SKILL.md`: the core skill instructions.
- `references/voice-examples.md`: examples and editing checks.

## Use in ChatGPT
For immediate use, paste text with a command such as:
- `Dunsin voice: [your draft]`
- `Humanize this and make it brief: [your draft]`
- `Reply to this Ward 5 resident, empathetic and accountable: [comment]`
- `Write a Facebook caption in Dunsin voice, with my campaign contact number: [topic]`
- `Polish only, don't change my message: [draft]`

For ongoing project use, copy the instructions from `SKILL.md` into the project's persistent instructions if the product supports that feature. In any compatible agent skills environment, place this folder in the environment's skills directory and follow that platform's skill installation documentation. Saving a file to GitHub is **not** the same as installing it in ChatGPT.

## Priorities
Naturalness over superficial "AI detection" games. Meaning over synonym-swapping. Accuracy over intensity. Brevity over filler.
